# Nuance Studio - Система записи к мастеру маникюра

Веб-приложение для записи клиентов в салон красоты с админ-панелью управления.

## Технологии

-Go (Gin) - Backend-фреймворк для обработки HTTP-запросов

-PostgreSQL - Реляционная база данных для хранения информации о клиентах, записях и мастерах

-HTML/CSS - Адаптивная вёрстка пользовательского интерфейса

-pgxpool - Пул соединений с PostgreSQL для эффективной работы с БД

## Функциональность

### Для клиентов
- Регистрация и вход
- Создание заявки на запись
- Выбор мастера и услуги
- Добавление комментария к записи

### Для администраторов
- Отдельный вход
- Изменение статуса записи (Запрос звонка / Подтверждена / Отменена)
- Редактирование даты, мастера и услуги
- Удаление записей
- Управление мастерами (добавление/удаление)
